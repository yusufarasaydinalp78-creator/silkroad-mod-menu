## 🧩 About

**Silkroad Online helpers** is a curated list of Silkroad Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, map viewer, route notes
- **Quality-of-Life Helpers** — inventory organizer, skill planner, config notes
- **Research Notes** — route layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Travel & Route Helpers
- Route Notes — plan trade and travel paths across regions
- Map Overlay — visualize map markers and waypoints
- Speed Notes — review movement timings in the editor
- Checkpoint Notes — save and revisit study checkpoints

### 🎒 Inventory & Skills
- Inventory Organizer — sort items and gear notes
- Skill Planner — organize skill builds and roles
- Item Catalog — browse items, sets, and rarity notes
- Buff Tracker — track active buffs for study

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any build
- Combat Log Notes — review encounter timings
- Party Comp Notes — organize group roles in the editor
